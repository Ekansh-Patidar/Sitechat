A page the widget knows nothing about

Everything here is set up to break an injected widget. Buttons are uppercase with a dashed red border, textareas are yellow, box sizing is forced to content-box with an important flag, and the body font is a serif. None of it should reach inside the chat panel.

The one thing that should cross over is the typeface. The widget inherits it on purpose, so it reads as part of the page rather than something pasted on top.

Open the chat, ask something, close it, and reload. The conversation should still be there. Resize below 520 pixels and the panel should take the whole screen. Press Escape and it should close.
